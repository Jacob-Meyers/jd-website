Reads EXIF and Metadata from files.

Current file support:

  • .jpg / .jpeg (JPEG Images with Exif segments)
  • .tiff / .tif (Standard TIFF Images)
  • .nef (Nikon Raw - TIFF structure base)
  • .cr2 (Canon Raw - TIFF structure base)
  • .dng (Adobe Digital Negative - TIFF structure base)
  • .pef (Pentax Raw - TIFF structure base)
  • .orf (Olympus Raw - TIFF structure base)
  • .arw (Sony Raw - TIFF structure base)
